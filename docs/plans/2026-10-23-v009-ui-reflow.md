# v0.0.9 UI Reflow Implementation Plan

Goal: keep the existing dark/mint visual language and query workflow while making the input stage more compact and sequential.

1. Move the event and date controls into a two-column row after log type; move the four client filters below it and remove the redundant help card.
2. Default valueX selection to empty, show five items per row with a two-row scroll viewport, and add a non-blocking hover/focus hint.
3. Move recent queries below PV/UV analytics, bump the local version, and update layout/browser tests without changing SQL or account data.
4. Verify desktop/mobile layout, keyboard interactions, and the existing Python test suite; keep changes local until the user approves GitHub upload.

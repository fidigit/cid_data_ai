# v0.0.5 筛选与结果展示

已确认的范围：在日志类型下方加入客户端 sys 多选、ver 空格分隔输入及 value1～25 返回列选择；WEB 不受这些字段影响。保持既有 UI，选项以内联展开区展示。

实现：
- QueryFilters 对系统、版本和列名白名单校验并规范化；空系统和版本不生成 WHERE，空 value 列仍保留基础字段及 value1 冷启动判断。
- 共用 SQL 计划生成用于估价与执行的两条 SQL；仅明细加 LIMIT，聚合保留全部匹配行。凭证绑定 SQL 计划摘要，包含筛选、返回字段和导出上限。
- 任务上下文增量存储 filters_json/export_limit，已有记录兼容默认值；旧版凭证需重新评估。
- 首 Sheet 聚合统计、次 Sheet 原始数据，流式最多写入20万条（若配置更低则取低值）。按聚合 PV 合计判断是否截取，恰好上限不显示截断提示；提示含无排序保证，UV 日合计不是区间去重。
- 查询按钮保留自动下载；图表默认 PV，右上角切换 UV，柱顶完整数字，切换不发送数据查询。

验证使用隔离 SQLite 和模拟 ODPS：筛选注入拒绝、默认/空列、条件变更凭证拒绝、两端估价执行一致、全量统计、空结果、20万行边界及工作表顺序；Edge 桌面/窄屏控件、历史和图表交互。未执行真实计费查询。

部署需停旧 API/Worker，备份 .env 与实际数据库，先启动 API 自动迁移，再启动 Worker。真实表字段和 sys 存储值需在目标环境确认。

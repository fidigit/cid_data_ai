# v0.0.4 WEB 日志查询

按确认的效果图在原界面增加客户端 / WEB端切换，默认客户端，不增加弹窗。

实现范围：
- 客户端沿用 event_detail.sql；WEB 使用 web_event_detail.sql，固定 yy_websdkprotocol_original，精确匹配单个8位 eventid。
- 同一 ODPS 账号 / 项目和日期格式；日期默认昨天、最多7天。WEB 不继承客户端过滤条件。
- build_query_plan 为估价和 Worker 提供同一对明细 / 聚合 SQL。
- 两次 execute_sql_cost 扫描量求和，再按已有单价估算金额；复杂度显示最大值。每日预算仍按估算金额累计，不代表实际账单对账。
- 凭证绑定日志类型并带版本号；任务上下文持久化类型；原数据库只增加字段，旧记录默认 client。
- XLSX 文件名标识端类型；WEB 明细保留原字段，聚合表增加 eventid，提示每日 UV 相加不等于区间去重。
- 切换端、日期、输入后废弃估价；过期异步响应不能重新解锁；执行导出期间锁定查询条件。

验证：Python API/Worker/下载一体测试使用模拟 ODPS，验证两次估价对应两次执行、预算拦截、空结果和 XLSX 内容；数据库迁移重复执行及旧记录保留；浏览器检查桌面/窄屏、端切换、历史、异步响应和导出锁定。

部署：停止 API/Worker，备份 .env 和数据库，更新依赖后启动 API（自动增加 log_type 字段），再启动 Worker。无需更改现有账号密码或客户端配置。WEB 表读取权限及实际 ODPS 联调需在目标环境确认。
